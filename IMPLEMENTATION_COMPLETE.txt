                            ERROR CODES REFERENCE
================================================================================

REGISTRATION ERRORS:
  ✓ INVALID_JSON (400) - Malformed JSON
  ✓ VALIDATION_ERROR (400) - Missing/invalid fields
  ✓ INVALID_EMAIL (400) - Invalid email format
  ✓ WEAK_PASSWORD (400) - Password doesn't meet requirements
  ✓ PASSWORD_BREACHED (400) - Password in breach database
  ✓ USER_EXISTS (400) - Email already registered
  ✓ RATE_LIMITED (429) - Too many attempts
  ✓ AUTH_ENV_MISSING (500) - Server misconfiguration

LOGIN ERRORS:
  ✓ INVALID_CREDENTIALS (401) - Wrong email/password
  ✓ ACCOUNT_LOCKED (429) - Account locked
  ✓ RATE_LIMITED (429) - Too many attempts
  ✓ USER_NOT_FOUND (401) - User doesn't exist
  ✓ SERVER_CONFIG_ERROR (500) - Server misconfiguration

SESSION ERRORS:
  ✓ NO_TOKEN (401) - Missing auth header
  ✓ INVALID_TOKEN (401) - Malformed/expired token
  ✓ BLACKLISTED_TOKEN (401) - Token revoked
  ✓ USER_NOT_FOUND (401) - User doesn't exist

                           QUICK START GUIDE
================================================================================

1. SET ENVIRONMENT VARIABLES
   JWT_SIGNING_KEY=$(openssl rand -base64 32)
   APPWRITE_SESSION_COOKIE_SECRET=$(openssl rand -base64 32)
   # Add to .env.local

2. TEST REGISTRATION
   curl -X POST http://localhost:3000/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "email": "test@example.com",
       "password": "SecurePass123!",
       "name": "Test User"
     }'

3. TEST LOGIN
   curl -X POST http://localhost:3000/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{
       "email": "test@example.com",
       "password": "SecurePass123!"
     }'

4. VALIDATE SESSION
   curl -X GET http://localhost:3000/api/auth/validate-session \
     -H "Authorization: Bearer {JWT_TOKEN}"
